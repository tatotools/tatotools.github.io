How we work

Tested on real output

Every fix is checked against a corpus of models generated for testing, imported in Unity 2022.3 LTS and Unity 6, and compared by render before and after.

Honest about limits

When a fix would damage your asset, the tool says so instead of doing it. For example, it tells you when a triangle budget needs a remesh rather than smearing your textures.

Built for agents too

Batch commands return JSON, so CI pipelines and coding agents can run the same checks you run in the editor window.
